> A brand-new shield system written in Kotlin, inspired by the Void Shield from Warhammer 40K.

---

## ✨ Features

- **Brand-New Instruction Set** — Drastically enhanced freedom in shield control
- **Brand-New Heat System** — A heat management experience completely different from the base game
- **Brand-New Shield Mechanics** — Refreshing and innovative gameplay

> ⚠️ Requires some basic knowledge of logic programming

---

## 🎮 What You Can Do

1. Create shields with custom shapes
2. Control shields via the Logic Processor
3. Continuously upgrade shields through block stacking and logic optimization

---

## 📖 How to Play

1. Build a **Void Heart**, a **Veil Dissolver**, a **Spatial Piercer**, and a **Logic Processor** to control the system
2. Set up an independent cooling line for the system
3. Write control logic

---

## 📝 Logic Scripting Guide

1. Use `CircleZone` (or other Zone commands) to create a zone
2. Use `UseZone` to load that zone into the corresponding block
3. Use `UpdateZone` to control that zone

> To enable bullet blocking: use `Bind` to bind the Veil Dissolver to the Spatial Piercer, then use `AutoBlock` to activate automatic interception.

This instruction set will continue to be expanded in the future.
